# Foundation decisions

## Scope baseline — 2026-09-13

This repository implements the MVP in `AGENTS.md`. It is a from-scratch product: do not copy TrailPrint-3D code or assets.

## Architecture

- **Client:** Vite + React + TypeScript. Leaflet is the only map library; Three.js is reserved for the generated-mesh preview.
- **API:** one TypeScript Node HTTP process. Geometry, projection, DEM adapters, validation, and STL encoding will be framework-independent modules under `src/`.
- **Delivery:** one Docker image will serve the built client and API after the core generation pipeline is proven.

## Provisional values — not production requirements

These give the first geometry tests a concrete contract and must remain visible in the UI as editable defaults:

| Setting | Provisional value | Status |
| --- | ---: | --- |
| Selection shape | rectangle, 4:3 aspect ratio | pending owner validation |
| Geographic footprint width | 2,400 m | pending owner validation |
| Printed width | 180 mm | pending owner validation |
| Base thickness | 3 mm | pending print testing |
| Vertical exaggeration | 1.5× | pending terrain testing |
| Route width / height | 1.2 mm / 0.6 mm raised | pending nozzle and slicer testing |
| Grid spacing | 20 m | synthetic-test starting point only |

## External services and licensing

- Vite is MIT licensed. Leaflet (BSD-2-Clause) and Three.js (MIT) are permitted code dependencies; retain third-party notices generated by the package manager.
- MapTiler is the leading candidate for map tiles and server-side elevation because it supplies an elevation API and uses API keys. Its free plan is non-commercial/evaluation only, so commercial production requires a reviewed paid plan, with its attribution and usage quotas observed. The key will remain server-only.
- No tile or DEM provider has been committed to production yet. Before enabling a provider, record the selected plan, terms review date, required attribution, cost/quotas, geographic coverage, resolution, and retry/error behavior here.
